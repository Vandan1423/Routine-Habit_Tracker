Loader ideas

Each one plays the same wait. The clock moves the drawing along but never finishes it; the last piece is placed when the server answers. Try a sleeping server and an awake one to see both ends.

उदय Sunrise

The app wakes the way a day does. A saffron sun climbs from behind the horizon, and the horizon is the Day Strip, filling as the sun rises.

When the server answers, the sun clears the horizon and the last segment fills.

शिरोरेखा The headline

नित्यक्रम is written one letter at a time while the server wakes. In Devanagari the line along the top, the shirorekha, is what joins separate letters into one word.

When the server answers, the headline is drawn in one stroke and the name is whole.

கோலம் Kolam

The pattern drawn at the doorstep every dawn in South India: the dots first, then one unbroken line around them. A daily ritual, which is what the app is for.

When the server answers, the line closes on the point where it began.

घटिका Water clock

India’s old clock: a copper bowl with a pinhole floats in water, fills and sinks once every 24 minutes. घड़ी, the everyday word for a clock, comes from it.

When the server answers, the bowl goes under and a ripple spreads. The closest of the five to the water site you saw.

श्वास Breath

The wait becomes something to do: breathe in for four seconds, out for four. A sleeping server takes about four breaths, which suits an app about keeping a routine.

When the server answers, the breath ends on the way out and the circle settles.
